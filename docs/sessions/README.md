# Session progress files

Each working session (Gavin's, Will's, the studio agent's; Claude or Codex) appends to `docs/sessions/<name>.md`: one line per finished step with time and commit, and a SESSION SUMMARY at the end, pushed before it stops. The current state lives in [`HANDOFF.md`](https://github.com/gavaiken/river-bitcube/blob/main/HANDOFF.md); see [`AGENTS.md`](https://github.com/gavaiken/river-bitcube/blob/main/AGENTS.md). Letters A–U are the Gray Area sessions (history).
